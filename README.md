# Jeyvar Prints – React + MUI

## Run
```bash
npm install
npm run dev      # http://localhost:5173
```

## Build for production
```bash
npm run build    # output in /dist
npm run preview
```

## Edit
- Phone / Instagram / WhatsApp helper: `src/config.js`
- Colors + fonts (MUI theme): `src/theme.js`
- All sections: `src/App.jsx`
- Images: `src/assets/`
